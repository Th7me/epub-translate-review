# 源文—译文审校量规

量规用于定位可观察的问题和决定修订优先级，不用于自动给译文文学质量打分。任何机械检查都不能替代完整源文—译文语义审校。

## 严重度

| 级别 | 可观察锚点 | 处理 |
|---|---|---|
| Blocker | 漏译/错位使文件无法封装或读者无法获得对应正文；关键节点、字段或标记损坏 | 先修复，再进入下一状态 |
| Major | 改变事实、关系、视角、动作施受、否定/条件、数字、称呼或系统触发；成人内容被删改或无依据扩写 | 必须回源修订并复查相邻字段 |
| Minor | 不改变事实但损害语气、语域、术语一致性、儿童声音、格式或可读性 | 批次内修订；无法确定则记录 |
| Query | 源文本自身歧义、损坏或证据不足，多个译法都可成立 | 保留候选、依据和暂定决定，不伪装确定 |

严重度由影响和证据决定，不由问题数量换算总分。量规不声称自动评定“文学性”“流畅度”或整体质量。

## 重点维度与微型例子

| 维度 | 通过锚点 | 反例（均为虚构短句） |
|---|---|---|
| 否定/条件 | 否定范围、条件和因果方向与源文一致 | 源文意为“不是因为下雨”，译成“因为下雨”——Major |
| 主语/动作 | 谁说、谁做、对谁做明确且不互换 | 源文意为“米娜推了杰”，译成“杰推了米娜”——Major |
| 儿童称呼与敬语 | 按关系和场景表达礼貌距离，保留称呼变化 | 小孩对年长者用敬称，译成“小孩叫他弟弟”——Major；不可只因 `형` 就统一为亲哥哥 |
| 习语/隐喻 | 传达语境意义，避免生硬字面破坏动作或笑点 | “嘴很重”若源意为“守口如瓶”，仍译“嘴很重”——Minor/Major，视情节影响 |
| 施受/感知 | 接收者、施动者、信息/气味/物件方向一致 | 源文意为“露娅闻到洛恩释放的气味”，译成“洛恩闻到露娅释放的气味”——Major |
| 视角/知识 | 当前角色只知道当前证据，误会和谎言保留 | 角色猜测“可能是蓝盒子”，译者按后文改成“就是蓝盒子”——Major |
| 特殊内容 | 系统字段、儿童日常、成人场景分别遵守标准 | 源文无性化的儿童玩笑被译成成人暗示，或成人明示动作被省略——Major |

## 审校记录模板

```text
位置：[章节/字段/节点]
级别：[Blocker/Major/Minor/Query]
类型：[遗漏/错位/主客体/否定/称呼/术语/视角/格式/其他]
源文证据：[逐字段描述或短标签，不复制大段正文]
现译问题：[可观察差异]
决定：[修订为…… / 保留并标 Query]
依据：[标准、索引、相邻上下文或明确源文]
```

## 交付前边界

- 字段数、非空、JSON/HTML/XML 结构、非法字符、资源链接等是机械检查；通过后仍须逐字段语义回源。
- 早期由主助手个人翻译并保留的章节，仍按同一量规重新读源文并记录审校状态；作者身份不构成免审依据。
- 审校者不把自动检查结果、模型自评分或“读起来顺”写成语义完成证明；没有实际证据的状态保持未确认。
